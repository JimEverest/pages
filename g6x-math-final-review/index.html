诊断03
单元 1 · 负数

正负数：表示相反意义的量

一句话目标

能用正负数记录相反意义的量，会在数轴上表示并比较大小。

为什么：零上/零下、收入/支出方向相反，只有 0 和正数不够用 → 比 0 低的记作负数。0 既不是正数也不是负数，它是分界线。
易错：−3℃ 与 −18℃ 谁冷？离 0 越远的负数越冷 → −18℃ 更冷。判断题："0 是正数" ✗。
负数04
单元 1 · 负数

数轴：从左到右越来越大

规则

  • 0 右边是正数，0 左边是负数
  • 正数 > 0 > 负数
  • 两个负数，离 0 越远的越小

走多远 vs 到哪里

蜗牛从 0 出发：+4、−2、+5、−7、+8

"到了哪里" → 求和：4−2+5−7+8 = +8

"走了多远" → 绝对值相加：4+2+5+7+8 = 26

马上练

① 在数轴上标出 −2.5、+1、−0.5
② −7 ○ −5.2　③ −3℃ ○ −18℃（谁低）
④ 向东 5m 记 +5，先 +5 再 −4，终点？

答案② <　③ −18℃ 低　④ +1m

生活原型：海拔（海平面=0）、警戒水位、净重 ±3g、电梯楼层。

单元 2 · 百分数(二)

折扣与成数

概念

几折 = 十分之几 = 百分之几十：八五折 = 85%；几成：三成五 = 35%。

现价 = 原价 × 折数
为什么：折扣是"现价占原价的百分率"，单位1 是原价。已知现价求原价 → 除以折数。
易错："打九折"是 ×90% 不是 −90%；一折出售 = ×10% = 降价 90%；折上折 = 原价×90%×85%，≠ 七五折。
百分数06
单元 2 · 百分数(二)

税率与利率

税率

应纳税额 = 应纳税部分 × 税率

例：营业额 40 万 × 5% = 2 万

利率

利息 = 本金 × 利率 × 存期

例：5000 元存 2 年，年利率 2.10% → 利息 5000×2.10%×2=210 元，共取 5210 元

马上练

50000 元存三年，年利率 1.30%，到期共取回多少？

解50000×1.30%×3 = 1950 → 50000+1950 = 51950 元

易错：①忘乘存期；②利率是年利率，存几年乘几；③"取回多少" = 本金+利息，别只答利息。
百分数07
单元 2 · 解决问题

选方案：分别算，再比较

教材例题：230 元的书包

A 商场：打 55 折 → 230×55% = 126.5 元

B 商场：每满 100 减 50 → 230−50×2 = 130 元

结论：A 更省（打折是全部生效，满减只对"凑满"部分生效）

马上练：480 元商品

A 店每满 100 减 40：480÷100=4.8 → 减 4 次 → 480−160=320 元

B 店七五折：480×75%=360 元 → A 店便宜 40 元

易错：满减必须看"够不够减"——只有 130 元时，每满 100 减 50 只能减一次；先算"能减几次"再算总价。
方法总结：方案比较题三步——①列出每种方案的总价算式；②分别算出结果；③比较后用一句话回答（"到哪家买便宜"）。

单元 3 · 圆柱与圆锥 ★

圆柱的认识与侧面展开

结构

3 个面：2 个完全相同的底面圆 + 1 个侧面（曲面）

为什么：沿高剪开摊平，底面圆滚一圈的长度 = 长方形的长 → 长 = 底面周长 C，宽 = 高 h。斜着剪是平行四边形（面积不变）。
易错：展开图的长是"周长 πd"，不是直径 d！底面周长=高时，展开图是正方形。
圆柱圆锥09
单元 3 · 圆柱与圆锥 ★

表面积：先数"有几个面"

S表 = 侧面积 + 2底面积 = 2πrh + 2πr²

例：r=4、h=6 → 侧 150.72，表 251.2 cm²

审题分类（最坑）

无盖水桶/水杯侧面 + 1 底
通风管/油管/压路机只算侧面
商标纸只算侧面
水池抹水泥侧面 + 底面

马上练：厨师帽

圆柱形厨师帽（无底），底面半径 10cm，高 30cm，做一顶至少用布多少？

解侧 2×3.14×10×30=1884，顶 3.14×10²=314 → 2198 cm²

为什么先数面：表面积是"所有露在外面的面之和"，实际物体常常少一个底或只要侧面——先想实物，再套公式。
圆柱圆锥10
单元 3 · 圆柱与圆锥 ★

圆柱体积：切拼成长方体

V = πr²h = 底面积 × 高

例：r=4、h=6 → 3.14×16×6 = 301.44 cm³

为什么：把圆柱切成 16 等份拼成近似长方体——形状变了、体积没变；底面变成长方形（长≈πr、宽≈r），所以 V = πr×r×h。
易错：r=1.5 时 r²=2.25 别算错；求高 → h = V÷S底；单位 dm³=L、cm³=mL。
圆柱圆锥11
单元 3 · 圆柱与圆锥 ★

圆锥体积：为什么要 ÷3

V锥 = ⅓ πr²h = ⅓ × 底面积 × 高
为什么：等底等高的圆锥装满水，倒 3 次正好装满圆柱。前提是等底等高！
易错：①不等底等高时不是 1/3（判断题陷阱）；②漏乘 ⅓；③圆锥的高是顶点到底面圆心，不是斜边。

马上练

r=3、h=2 → 3.14×9×2÷3 = 18.84 m³；等底等高圆柱 18dm³ → 圆锥 6dm³

圆柱圆锥12
单元 3 · 提优专项

切割与"削"：先问增加了哪几个面

操作表面积变化体积
沿直径竖切1刀+2 个矩形面 = 2dh不变
横切1刀+2 个底面圆 = 2πr²不变
削成最大圆锥—→ 原来的 ⅓
切拼成长方体+2 个 r×h 面不变

例（教辅 P32）

竖切 2 块增 48cm²，h=6 → 2dh=48 → d=8，r=4 → V=3.14×16×6=301.44cm³

截 3 段增 50.24cm² → +4 个底面圆 → r=2；长 2m=200cm → V=2512cm³

方法：先画"新增面"长什么样（矩形 d×h？圆 πr²？），再列差值算式。横截 n 段增 2(n−1) 个底面。
圆柱圆锥13
单元 3 · 提优专项

圆柱圆锥 + 比：先平方再分配

两条规则

  • 半径比 → 面积比要平方：r₁:r₂=2:1 → S₁:S₂=4:1
  • 等底等高：V柱:V锥 = 3:1

例（教辅 P32）

圆柱圆锥半径比 2:1、高比 1:3，体积和 31.4cm³

体积比 = (4×1):(1×3×⅓) = 4:1

圆柱 = 31.4×⅘ = 25.12　圆锥 = 6.28 cm³

马上练

①等高等体积的圆柱圆锥，底面积比？
②体积相等、底面积相等，圆柱高 4cm，圆锥高？
③半径比 3:2、高比 2:3 的两圆柱体积比？

答案①1:3　②12cm　③(9×2):(4×3)=18:12=3:2

为什么平方：S=πr²，r 扩大 2 倍，r² 扩大 2×2=4 倍——面积是"两个维度"的乘积。

单元 4 · 比例 ★

比例的意义与基本性质

比例：两个比相等的式子，如 2.4:1.6 = 60:40（比值都是 1.5）

外项积 = 内项积：a:b = c:d ⟺ ad = bc
为什么：a/b = c/d 两边同乘 bd → ad = bc。这就是解比例的依据。
易错：比（两个数相除，一个值）≠ 比例（四个数的等式）。判断 4 个数能否组比例：最大×最小 是否 = 另两数之积。
比例15
单元 4 · 比例 ★

解比例：转化为乘积式

类型 1

3 : 8 = x : 32

8x = 3×32 → x = 96÷8

x = 12

类型 2（分数形式）

x / 9 = 4 / 6

交叉相乘：6x = 36

x = 6

类型 3

1.5 : 2.5 = 6 : x

1.5x = 15 → x = 15÷1.5

x = 10

易错：先看 x 在内项还是外项，再决定乘谁除谁；解完代回检验两个比值是否相等。
比例16
单元 4 · 正反比例 ★★

正比例：比值一定

y ÷ x = k（一定）

判断三步：①相关联？②同向变化？③比值一定？

例：速度一定，路程÷时间 = 定值 → 正比例；图像是过原点的直线

反例：正方形面积与边长（比值=边长，在变）不成比例；人的年龄与身高不成比例。
比例17
单元 4 · 正反比例 ★★

反比例：乘积一定

x × y = k（一定）

例：路程一定，速度×时间 = 定值 → 反比例

数量关系一定量类型
速度 × 时间路程反比例
总价 ÷ 数量单价正比例
每天烧煤量 × 天数煤总量反比例
长一定，面积与宽长正比例
周长一定，长与宽—不成比例

马上练（判断）

①比例尺一定，图上距离与实际距离？
②长方形面积一定，长与宽？
③圆锥体积一定，底面积与高？
④全班人数一定，出勤人数与出勤率？

答案①正　②反　③反　④正

口诀背后：找"哪两个量在变、哪个量不变"，把关系写成乘法或除法，不变的是积就是反比例，不变的是商就是正比例。

单元 4 · 比例的应用

比例尺：单位要统一

比例尺 = 图上距离 : 实际距离

1:1000000 → 图上 1cm = 实际 10km（km→cm 要 ×100000）

马上练

①图上 5cm 表示实际 250km，比例尺？
②1:6000000 图上 4.5cm，实际多少 km？
③线段比例尺 1cm 代表 40km，写成数值比例尺？

答案①1:5000000　②4.5×6000000=27000000cm=270km　③1:4000000

易错：①先统一单位再化简；②比例尺不带单位；③放大比例尺前项>1（2:1 = 图上是实际的 2 倍，精密零件图）。
为什么：比例尺就是"图与实的比"，比的前后项必须同单位——这就是为什么 km 要换算成 cm。
比例19
单元 4 · 比例的应用 ★★

用比例解决问题：四步路线图

路线图

1找不变量 → 2判正/反比例 → 3列比例 → 4解+检验

正比例例

3 小时行 420km，5 小时行多少？速度一定：
420/3 = x/5 → x = 700 km

反比例例

每天运 30t 需 8 天，每天运 40t 几天？总量一定：
30×8 = 40x → x = 6 天

提优：顺风逆风（教辅 P55）

燃料最多飞 7 小时，去时顺风 800km/h，返回逆风 600km/h，最远飞出多少就要返回？

路程一定 → 反比例：800×t = 600×(7−t)

1400t = 4200 → t = 3 → 800×3 = 2400 km

为什么要用比例：当"每天产量一定""总量一定"时，比例是更自然的等量关系——它直接表达"不变的量"。

单元 5 · 数学广角

鸽巢问题：最不利原则

为什么总有 1 个筒至少 2 支？

用最不利想：让每个筒都尽量少——先各放 1 支（3 支用完），第 4 支只能再进某筒。

物体数 ÷ 鸽巢数 = 商……余数 → 至少数 = 商 + 1
易错：有余数时至少数是商+1，不是商+余数：25÷8=3…1 → 至少 4 只，不是 5。摸球题先"拿光"其他种类：4 红 3 蓝保证同色 → 2+1+1=4。

数与代数：过一遍全网

数的认识

  • 大数读写、改写"万/亿"（精确）vs 四舍五入（近似）
  • 小数/分数/百分数互化；负数
  • 2/3/5 倍数特征、质数合数、奇偶

数的运算

  • 运算律：交换/结合/分配：(a+b)×c
  • 简算：a−b−c = a−(b+c)
  • 先乘除后加减，括号优先

式与方程

  • a² ≠ 2a；0.5a = a/2
  • 等式性质解方程，解完检验
  • 列方程解应用题：设、列、解、验、答

比和比例

  • 化简比（仍是比）≠ 求比值（一个数）
  • a:b = a/b = a÷b（后项≠0）
  • 按比分配、正反比例

图形与几何：公式一张网

图形面积/体积
平行四边形S = ah
三角形S = ah÷2

统计与概率 · 数学思考

统计图怎么选

  • 条形：比多少
  • 折线：看变化趋势
  • 扇形：部分占整体的百分比
  • 平均数 = 总量 ÷ 总份数

可能性

扑克 54 张抽 1 张：黑桃概率 13/54；梅花+方块 = 26/54 = 13/27。可能性 = 符合结果数 ÷ 总结果数。

找规律

9×9−1=80，98×9−2=880，987×9−3=8880 → 规律外推：98765×9−5 = 888880

逻辑推理

等量代换：△+□=10，△=□+2 → □=4，△=6。列表枚举不重不漏。
