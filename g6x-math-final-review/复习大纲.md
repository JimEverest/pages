## 一、负数（教材 p2–7）

**一句话目标**：能用正负数表示相反意义的量，会在数轴上表示并比较大小。

### 1.1 正负数的意义
- **为什么**：生活中有"正好相反"的量——零上/零下、收入/支出、向东/向西。只有 0 和正数不够用，于是比 0 低的记作负数。**正负号表示的是"意义相反"，不是"大小多少"**。
- **直观模型**：温度计（0℃ 是冰水混合物）；电梯楼层（地面 0 层，地下 −2 层）；账单 +500 收入 / −500 支出。
- **关键规定**：0 既不是正数，也不是负数——它是正负的分界，是"标准"。
- **易错提醒**：
  - 0 不是正数也不是负数（判断题最爱考）。
  - "-4℃ 比 -1℃ 冷"——负号不是"小"的意思，离 0 越远越冷。
  - 非零自然数前加"+"还是正数，加"−"变负数，但 3 和 +3 是同一个数。
- **马上练**：①收入 800 元记作 +800，支出 500 元记作____；②一种饼干净重 197g，比标准多 3g 记 +3，少 3g 记____（包装上 ±3 g 是什么意思）；③写出 3 个正数、3 个负数、并说明 0 的地位。

### 1.2 数轴与大小比较
- **为什么**：数轴把"意义相反"画成"方向相反"：0 右为正、0 左为负。数轴上**从左到右越来越大**——这就是比较大小的一切规则的来源。
- **直观模型**：数轴跳格子；温度计竖起来就是竖着的数轴。
- **规则**：正数 > 0 > 负数；两个负数，离 0 越远的越小（−18 < −3）。
- **易错提醒**：−3 > −18 常被写成 −3 < −18。口诀"负数比大小，绝对值大的反而小"，但要回到数轴理解，不是背口诀。
- **马上练**：①在数轴上标出 −2.5、+1、−0.5、−1/2；②比较：−7 ○ −5.2、−3℃ ○ −18℃（谁温度低）；③春游向东风 5m 记 +5，向西 4m 记 −4，小虫从 0 出发 +5 再 −4，终点是几？

### 1.3 用负数解决实际问题
- 模式：先定标准（0 在哪里），再记数。如：警戒水位为 0，高于 1.5m 记 +1.5；低于 0.3m 记 −0.3。
- 提优（教辅 P2 第2关）：蜗牛来回爬 +4、−2、+5、−7、+8 → 到达点 = 求和；(1) 每爬 1 格奖励一颗星：爬过的路程 = 各数绝对值之和。**"走了多远"用绝对值，"到了哪里"用代数和**。

## 二、百分数（二）（教材 p8–15）

**一句话目标**：会用折扣、成数、税率、利率解决实际问题，会比较购物方案。

### 2.1 折扣
- **为什么**：几折 = 十分之几 = 百分之几十。八五折就是按原价的 85% 出卖。"折扣"是现价占原价的百分率。
- **公式**：现价 = 原价 × 折数（如 280×85%=238 元）。
- **易错提醒**：
  - "打九折"是乘 90%，不是减 90%；160×(1−90%)=16 是"降价 90%"（一折出售）。
  - 「折上折」：先打九折再打八折 = 原价 × 90% × 80%，不等于打七折。
  - 单位 1 是**原价**，不是现价。已知现价求原价要**除以**折数。
- **马上练**：①原价 105 元的书打八折是多少？②一件衣服打折后 340 元，是原价的八五折，原价多少？③做一做：280×85% = ____，160×(1−90%) = ____。

### 2.2 成数
- 几成 = 十分之几：三成 = 30%；"增产二成五" = 25%。
- **易错**：成数只用于增减幅度，常与"比去年"连用，单位 1 是去年（或原本）的量。350×(1−25%)=262.5（去年 350，今年减少 25%）。
- **马上练**：①某乡去年水稻 350 吨，今年比去年增产二成，今年多少吨？②某品牌手机降价一成五，现价 4250 元，原价多少？

### 2.3 税率
- 应纳税额 = 应纳税部分（销售额/营业额）× 税率。30 万 × 3% = 0.9 万。
- **易错**：税是按"应纳税部分"算，不一定是全部收入（材料题爱设坑）。
- **马上练**：①某饭店 4 月营业额 40 万，按 5% 缴营业税，缴多少？②购车购置税：燃油车按车价 10%，新能源减半——18 万的新能源车缴多少？

### 2.4 利率 ★
- **为什么**：利息是银行使用你存款的"报酬"。**利息 = 本金 × 利率 × 存期**；取回总额 = 本金 + 利息。
- 例（教材原题）：5000 元存 2 年，年利率 2.10% → 利息 5000×2.10%×2=210，共取 5210 元。
- **易错提醒**：
  - 忘乘存期（×2）。
  - 利率是**年**利率，存 3 年要 ×3（素养题：5 万存三年 1.30% → 50000×1.30%×3=1950，共取 51950）。
  - 国债/教育储蓄常"免利息税"，普通题利息税另算时要看清税率。
- **马上练**：①8000 元存 3 年，年利率 2.75%，到期利息？共取回？②对比：同样存 2 年，方案 A 年利率 2.10% 整存整取，方案 B 买年化 2.0% 的理财按复利——两年后谁多？

### 2.5 选择最优方案（解决问题）★★
- **为什么**：满减（每满 100 减 50）只在"凑满"的整数倍上生效；打折是对**全部**生效。总价不同、凑整情况不同，结论就不同——所以必须**分别算、再比较**。
- 教材例：一套 230 元，A 商场打 55 折：230×55%=126.5；B 商场每满 100 减 50：230−50×2=130 → A 更省。
- **易错**：满减要看"够不够减"（每满 100 减 50，只有 130 元时只能减 50）；折上折、会员卡叠加要按顺序乘。
- 教辅提优（P12-1）：储蓄单读图表——到期共取 = 本金 + 本金×年利率×存期，从存单上找"存期""年利率"两个关键数据。
- **马上练**：①妈妈买 480 元的东西，A 店"每满 100 减 40"，B 店"七五折"，哪家便宜？②张老师买车：燃油车 14 万（购置税 10%，年使用费 1.2 万），新能源 18 万（购置税减半，年使用费 0.35 万），10 年总花费谁省？

## 三、圆柱与圆锥（教材 p16–37）★★★ 期末最大计算板块

**一句话目标**：认识圆柱圆锥的结构，会用公式算表面积和体积，会解决"切割/削/熔铸/比"类提优题。

**地基检查**（先做再学）：r=3 时，d=? C=? S=?（d=6, C=18.84, S=28.26）——这条链不熟，后面全卡。

### 3.1 圆柱的认识
- 3 个面：2 个完全相同的底面圆 + 1 个侧面（曲面）。
- **侧面展开图**（核心直观模型）：沿高剪开 → **长方形**，长 = 底面周长 C，宽 = 高 h。
  - 为什么：把侧面沿一条高剪开摊平，底面圆滚一圈的长度就是长方形的长。
  - 斜着剪开是平行四边形（面积不变）；底面周长 = 高时展开是正方形。
- **易错**：侧面展开长方形的长是"周长 C=πd"，不是直径 d。

### 3.2 圆柱的表面积
- S表 = 侧面积 + 2×底面积 = **2πrh + 2πr²**。
- **为什么**：表面积 = 所有外面的面之和 = 侧面长方形 + 上下两个圆。
- **审题分类**（期末最坑处，先想"有几个面"）：
  - 无盖水桶/水杯：侧面 + **1 个**底
  - 通风管/油管/压路机：**只算侧面**
  - 商标纸：只算侧面（或按题意）
  - 圆柱形水池抹水泥：侧面 + 底面
- **马上练**：①底面半径 2dm、高 5dm 的圆柱，侧面积、表面积？②一顶圆柱形厨师帽（无底），底面半径 10cm，高 30cm，做一顶至少用布多少？③压路机前轮半径 0.5m，宽 1.5m，转一周压路多少平方米？

### 3.3 圆柱的体积 ★
- **V = πr²h = 底面积 × 高**。
- **为什么（推导）**：把圆柱底面分成许多相等扇形，切开拼成一个**近似长方体**——底面变成近似长方形（长≈πr，宽≈r），高不变；长方体体积 = πr × r × h = πr²h。切拼过程形状变、**体积不变**。
- 由此还有两个常用变形：长方体切拼后新增了左右两个面（各 r×h）——这是提优题考法。
- **易错**：
  - r² 别算错：r=1.5 时 r²=2.25；π×2.25×h。
  - 单位：底面积是平方单位，体积是立方单位；dm³ = L，cm³ = mL。
  - 求高：h = V ÷ S底；求底面积：S = V ÷ h（逆用公式）。
- **马上练**：①r=4cm，h=6cm，V=? ②一根圆柱形钢材底面直径 10cm，长 2m，体积多少立方厘米？③圆柱水桶底面直径 40cm，高 50cm，能装水多少升？

### 3.4 圆锥的认识与体积 ★★
- 1 个底面圆 + 1 个侧面（展开是扇形）；从顶点到底面圆心的距离是**高 h**（只有 1 条）。
- **V = ⅓πr²h = ⅓ × 底面积 × 高**。
- **为什么（实验直观）**：等底等高的圆锥装满水，倒 3 次正好装满圆柱 → 圆锥体积是圆柱的 1/3。**前提：等底等高**！
- **易错提醒**：
  - 不等底等高时，圆锥体积**不是**圆柱的 1/3（判断题高频陷阱）。
  - 圆锥体积公式漏乘 ⅓。
  - 圆锥的高要从顶点量到圆心，不是母线（斜边）。
- **马上练**：①r=3m，h=2m 的圆锥沙堆，V=? ②等底等高的圆柱和圆锥，圆柱体积 18dm³，圆锥多少？圆锥 18，圆柱多少？③工地沙堆底面周长 25.12m，高 1.5m，这堆沙重多少吨（每 m³ 沙 1.7 吨）？

### 3.5 解决问题：容积、熔铸、浸没
- 容器厚度忽略时容积 ≈ 体积公式（用**内**尺寸）。
- **浸没排水**：物体体积 = 上升（下降）水的体积 = S底 × 水面变化高度。
- **熔铸/形变不变积**：熔铸前后体积相等——这是列式的锚。
- 教辅提优例（P30-2 错题分析）：圆柱容器装满水，放入 5 根 r=2cm、h=10cm 的圆柱小棒，溢出水 = 5×π×2²×10=628——**"溢出的是棒浸入部分的体积"**。

### 3.6 ☆专项：切割与"削"的问题（教辅 P32 专项一）
| 操作 | 表面积变化 | 体积变化 |
|---|---|---|
| 沿底面直径竖切 1 刀（2块） | 增加 **2 个矩形面** = 2dh（d=2r） | 不变 |
| 横切 1 刀（平行底面） | 增加 **2 个底面圆** = 2πr² | 不变 |
| 削成最大的圆锥 | 不变 | 变为原来的 **1/3**（削去 2/3） |
| 截短 h 减少 a | 减少 S底×a 的一部分（侧面积减少 2πr×a） | 减少 πr²a |
- **方法**：先问"增加/减少的是哪几个面、每个面长什么样"，列出差值方程。
- 教辅例1 校验：竖切 2 块增 24 → dh×2=24，若 d=4 则 h=3；横切 3 块增 50.24 → 4πr²=50.24 → r²=4。V=πr²h=3.14×4×3=37.68；削最大圆锥减少 37.68×⅔=25.12。
- **马上练**：①一根圆柱横截 2 段，表面积增加 25.12cm²，底面积多少？②把圆柱竖切成两半，表面积增加 48cm²，已知 h=6，求 r 和 V。③一个圆柱削去 25.12dm³ 后是最大的圆锥，原来圆柱体积多少？

### 3.7 ☆专项：圆柱圆锥 + 比（教辅 P32 专项二）
- **半径比 → 面积比要平方**：r₁:r₂=2:1 → S₁:S₂=4:1。
- 等底等高：V柱:V锥 = 3:1；V柱 = V锥 时：若底面积相等则 h锥 = 3h柱。
- **方法**：先把"体积和（差）"按比例分配，再还原各自体积。
- 教辅例2：圆柱圆锥底面半径比 2:1、高比 1:3 → 体积比 = (4×1):(1×3×⅓) = 4:1，和 31.4 → 圆柱 25.12、圆锥 6.28。
- **马上练**：①圆柱圆锥等高等体积，底面积比？②两圆柱底面半径比 3:2，高比 2:3，体积比？③一个圆柱与一个圆锥体积相等、高的比 4:9，圆锥底面积 25.12cm²，圆柱底面积多少？

## 四、比例（教材 p38–66）★★★ 概念+应用双重点

**一句话目标**：理解比例的意义与性质，会解比例；能判断正反比例；会用比例尺和比例解决问题。

### 4.1 比例的意义与基本性质
- **比例**：表示两个比**相等**的式子。2.4:1.6 = 60:40（比值都是 1.5）。判断方法：比值是否相等。
- **基本性质**：a:b = c:d ⟺ **ad = bc**（两外项之积 = 两内项之积）。
- **为什么**：a:b=c:d 即 a/b = c/d，两边同乘 bd 得 ad = bc。这是解比例的依据。
- **易错**：
  - 比与比例不同：比是两个数相除（一个值），比例是**四个数组成的等式**。
  - 组比例：4 个数要能组成比例，最大×最小 = 另两个数之积（判断技巧）。
- **马上练**：①3:4 与 4.5:6 能否组成比例？②在 24:16 = 9:6 中，外项是____内项是____，验证内项积=外项积；③把 6×8 = 3×16 改写成比例（写 2 个）。

### 4.2 解比例 ★
- 方法：把比例转成"外项积 = 内项积"，即解形如 x×a = b×c 的方程，x = (bc)/a。
- **易错**：x 在内项还是外项位置要看清；分数形式比例（x/4=9/12）先交叉相乘。
- **马上练**：①3:8 = x:32；②x/9 = 4/6；③1.5:2.5 = 6:x。

### 4.3 正比例 ★★
- **定义**：两种相关联的量，**比值（商）一定**时，y/x = k（一定）。路程÷时间 = 速度一定 → 正比例。
- **图像**：从原点出发的一条**直线**（过 (0,0)）。
- **判断三步**：①两量是否相关联变化？②一个量变大另一个也变大（同向）？③比值一定？三个都满足才是正比例。
- **反例（非正比例）**：正方形面积与边长（比值为边长，在变）；人的年龄与身高（不成比例）。
- **马上练**：①每本练习本 2 元，总价与本数成什么比例？②圆的周长与半径？面积与半径呢？③判断：长方形面积一定，长与宽（？）；长一定，面积与宽（？）。

### 4.4 反比例 ★★
- **定义**：**乘积一定**时，xy = k（一定）。速度×时间 = 路程一定 → 反比例。
- **图像**：曲线（双曲线，小学不要求画）。
- **判断三步**：相关联？一个变大另一个变小（反向）？乘积一定？
- **典型正/反比例对照表**：
  | 关系 | 一定量 | 类型 |
  |---|---|---|
  | 速度×时间 | 路程 | 反比例 |
  | 路程÷时间 | 速度 | 正比例 |
  | 单价×数量 | 总价 | 反比例 |
  | 总价÷数量 | 单价 | 正比例 |
  | 每天烧的量×天数 | 煤总量 | 反比例 |
  | 出勤人数/总人数 | 出勤率 | 正比例 |
  | 长方形面积一定，长×宽 | 面积 | 反比例 |
- 教辅提优（P55 例）：铁球浸没排水，水面降 0.5cm 对应铁球体积；棱 3cm 铁块水面升 0.3cm。**V = S×h 中 S 一定 → V 与 h 成正比例**，列 V₁/0.5 = V₂/0.3。
- 蜡烛题（期末提优 P111-8）：每分钟燃烧长度一定 → 燃烧掉的长度与时间成正比例；剩余长度 = 原长 − 燃烧长度。10 分钟烧剩 11cm、16 分钟烧剩 8cm → 每分钟烧 (11−8)/6=0.5cm → 原长 11+10×0.5=16cm。
- **马上练**：①判断正/反/不成比例：a) 比例尺一定，图上距离与实际距离；b) 长方形周长一定，长与宽；c) 全班人数一定，出勤人数与出勤率；d) 圆锥体积一定，底面积与高。②一根 24m 的绳子剪成若干段，每段长与段数？③播种天数一定，每天播种公顷数与总公顷数？

### 4.5 比例尺 ★
- **比例尺 = 图上距离 : 实际距离**（同单位！）。1:1000000 表示图上 1cm = 实际 10km。
- 形式：数值比例尺（1:500000）、线段比例尺（一段标 50km）、文字比例尺。
- **换算**：线段 → 数值：1cm 代表 50km = 5,000,000cm → 1:5000000。
- **易错**：
  - 单位统一：km→cm 要 ×100000；求实际距离常用 km 表达。
  - 比例尺不带单位、前项通常化 1。
  - 放大比例尺（精密零件）前项大于 1：2:1 表示图上是实际的 2 倍。
- **马上练**：①地图上 5cm 表示实际 250km，比例尺多少？②在 1:6000000 地图上量得两城 4.5cm，实际多少 km？③把线段比例尺（1 段 1cm 代表 40km）改写成数值比例尺。

### 4.6 图形的放大与缩小
- 按 2:1 放大：每条边 ×2；按 1:2 缩小：每条边 ÷2。**形状不变，大小变**；对应角不变。
- 放大后面积是原来的 4 倍（边长 2 倍 → 面积 2² 倍），提优常考。
- **马上练**：①三角形按 3:1 放大，底和高怎样变化？面积变为几倍？②一个长 4cm 宽 3cm 的长方形按 1:2 缩小后周长、面积各多少？

### 4.7 用比例解决问题 ★★
- **路线图**：判定量 → 找不变量 → 判断正/反 → 列比例 → 解 → 检验。
- 正比例题：2 天做 250 件 → 700 件需 x 天：250/2 = 700/x（每天产量一定）。
- 反比例题（教辅 P55-3）：燃料最多飞 7 小时，去时顺风 800km/h、回时逆风 600km/h，最远飞出多少需返航？800×t去 = 600×(7−t去)（路程一定→反比例）→ t去=3 → 2400km。
- **马上练**：①一列火车 3 小时行 420km，照这样 5 小时行多少 km（正比例解）？②一批货物，每天运 30t 需 8 天；每天运 40t 几天运完（反比例解）？③装修队铺地砖，每块 0.16m² 需 90 块；改用 0.36m² 的需多少块？

### 4.8 ☆"自行车里的数学"（教材 p65）
- 蹬一圈走的距离 = 车轮周长 ×（前齿轮齿数/后齿轮齿数）。
- **为什么**：链条传动，前齿轮转 1 圈带动链条走过"齿数"个齿，后齿轮跟着转 齿数比 圈。
- 变速自行车：前 3 × 后 6 = 18 种组合（去重后可能少于 18），齿数比越大走得越远但越费力。

## 五、数学广角——鸽巢问题（教材 p67–70）

**一句话目标**：会用"最不利原则"和 ⌈物体数÷鸽巢数⌉ 说明"至少"问题。

- **为什么**：4 支铅笔放 3 个笔筒，为什么总有 1 个筒至少 2 支？——用"最不利"想：让每个筒都尽量少，先各放 1 支（3 支用完），第 4 支只能再进某个筒。**"至少" = 最坏情况下也躲不掉的数**。
- **公式**：物体数 ÷ 鸽巢数 = 商 …… 余数 → 至少数 = **商 + 1**（有余数时）。即 ⌈a/b⌉。
- **易错**：
  - 有余数时至少数是商+1，不是商+余数（7 只鸽子 3 巢 → 至少 3 只，不是 4）。
  - "至少"问题要反向构造：要保证 X，最坏情况先被"拿光"的是其他种类（摸球问题：4 红 3 蓝 2 黄，保证 1 对同色至少摸 4 个；保证 1 红：至少摸 3+2+1=6 个）。
- **马上练**：①6 只鸽子飞进 5 个笼，总有 1 笼至少几只？②13 名学生中，至少有 2 人生日在同一月，为什么？③一副扑克 54 张，至少抽几张必有 2 张同花色？至少抽几张必有 1 张黑桃？（提示：大小王）

## 六、整理和复习（教材 p71–118）——小学总复习四大板块

### 6.1 数与代数
- **数的认识**：整数（亿级读写、改写"万/亿"做单位、四舍五入求近似数）、小数、分数、百分数、负数；数的整除（因数倍数、2/3/5 倍数特征、质数合数、奇偶）。
  - 易错：改写（精确，90000=9万）≠ 求近似数（≈，四舍五入）；2.5 万 = 25000。
- **数的运算**：四则运算顺序、运算律（a+b+c、a×b×c、分配律 (a+b)×c）、简算技巧。
  - 易错：12.5×28−193 = 350−193=157（先乘后减）；73.05−3.96 ≈ 73−4，精确 69.09；连续减 a−b−c = a−(b+c)。
- **解决问题**：分数百分数应用（单位1 已知用乘、未知用除/方程）、行程、工程（把总量当"1"）。
- **式与方程**：用字母表示数、等式性质、解方程、列方程解应用题。
  - 易错：a² ≠ 2a；0.5a 与 a/2 相同；方程检验代入原式。
- **比和比例**：比的意义/化简/比值、比与分数除法关系（a:b = a/b = a÷b，比的后项≠0）、按比分配、比例意义与性质、正反比例。
  - 易错：化简比（结果仍是比）vs 求比值（结果是一个数）；0.9×0.9 ○ 0.9；a/3 + b/4 与 (a+b)/12 的大小比较（通分验证）。

### 6.2 图形与几何
- **平面图形**：长方形/正方形/三角形/平行四边形/梯形/圆的面积公式及推导（转化思想：割补、剪拼）；组合图形面积（加减分割）。
- **立体图形**：长方体/正方体/圆柱/圆锥的表面积、体积公式系统表；等积变形。
- **图形的运动**：平移（方向+距离）、旋转（中心+方向+角度）、轴对称（对称轴条数）。
- **图形的位置**：数对 (列,行)；方向+角度+距离确定位置（北偏东 30°）。

### 6.3 统计与概率
- 统计图选择：条形（比多少）、折线（看变化趋势）、扇形（看部分与整体百分比）。
- 平均数 = 总量÷总份数；可能性 = 符合条件的 outcome 数 ÷ 总 outcome 数（如扑克抽梅花/方块的概率）。

### 6.4 数学思考
- 找规律（9×9−1=80, 98×9−2=880, 987×9−3=8880, … 规律外推）；列表枚举；逻辑推理（等量代换、简单假设）。
