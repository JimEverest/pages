01基础必会

先找基准，再谈正负

能说清一个负数相对于什么、向哪个方向变化。

为什么

正负号告诉我们相反方向；绝对值告诉我们变化多少。零是约定的分界，0℃不是没有温度。先统一基准，数字才可比较。

  • 实际量 = 标准量 + 偏差；例如标准500 g，偏差 g，实际为497 g。
  • 位置变化记正负；路程累计取每段的绝对值。收入与支出意义相反，收入与盈利不是一对相反意义的量。
  • 时差先写成“当地时间 = 北京时间 + 题设时差”。反求北京时要减去时差，并检查跨日。

时差为什么不能凭“早、晚”猜加减？

照片给定纽约时差 h：纽约9月1日10:45出发，对应北京9月1日22:45；再加14 h 55 min，得到9月2日13:40。也可先算纽约到达时间9月2日01:40，再加12 h。

别掉进这个坑

只写13:40没有日期，跨日应用题的答案就不完整。分钟按60进位，不能把10:45当10.45小时。

题目怎样变化：换基准；反求标准量；跨午夜时差；从正负记录分别求最终位置和总路程。

02圈题重点

有理数：看本质，不看外衣

判断一个数能否写成两个整数之比，并用两条分类轴归类。

为什么

“有理”不是“讲道理”，而是数能写成，其中是整数且。小数、百分数、分数线只是写法。

  • 按整数性：整数（正整数、0、负整数）与非整数有理数（分类中常称分数）。归入整数。
  • 按正负：正有理数、0、负有理数；正负分类和整数性可以交叉。
  • 有限小数、无限循环小数是有理数；无限不循环小数不是。是有限小数；和不是有理数。
  • 和都是有理数，只是的近似值，不能因为用于近似就改变类别。

拆开阳光P6第2题

8个数中，排除和（题设说明两个3之间的2越来越多，非循环）。其余共6个有理数。省略号本身不能证明“不循环”，须看完整规律。

别掉进这个坑

0既不是正数也不是负数，但它是整数、有理数、非负数。分类看数值，不看是否写了分数线。

题目怎样变化：统计个数；填写集合；交集图；判断“π的近似值”；给循环小数和有规律但不循环的小数作对照。

03圈题重点

边界、反例与奇偶：让“一定”站得住

遇到“所有、一定、至少、至多”时，能找边界或解释必然性。

为什么

一个反例足以推翻“一定”；几个例子都对，却不能证明对所有数都成立。0、1、−1和接近0的分数是很好的检查点。

  • 最小正整数为1；最大负整数为；最小非负数为0。没有最小整数，也没有最小正数（正数除以2更小且仍为正）。
  • “非负”包含0；“非正”包含0；负数没有最大的一个，但负整数有最大值。
  • 三个整数只有奇、偶两种类别，至少两个同奇偶；这两个数的和为偶数，因此它们的平均数是整数。

阳光P7能力提升2：三个平均数

至少一个是整数。三数全同奇偶时三个都是；两奇一偶或两偶一奇时恰好一个是。不可能恰好两个。反例立即否定“至多一个”。

别掉进这个坑

“至少一个”允许一个、两个或三个；题中实际只出现一个或三个。不要把“至少”误读成“恰好”。

题目怎样变化：真假判断并举反例；从“可能”升级到“一定”；改变整数个数或平均数条件。

怎样判断“真的会了”？

  1. 不翻资料，可以用一句话说明为什么。
  2. 能独立算对基础题，并解释至少一个容易混淆的反例。
  3. 换一个数字、方向或问法，仍能认出同一模型。
  4. 隔一段时间重新作答，不靠记住答案。

给错题标一个原因：概念 / 符号 / 顺序 / 漏解 / 读题与单位。先改原因，再做同类新题。避免把每道错题都归因于“粗心”。
