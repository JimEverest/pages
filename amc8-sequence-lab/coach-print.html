01 · 本轮究竟探测什么？

将“会不会”拆成四层。答案相同，证据可能很不同；答案错误，也可能只错在最后一次计算。不要合成一个分数掩盖区别。

观察层要看的证据不要过度推断
结果答案是否完整，单位、项数、选项是否对应题问一次答对可能来自猜测；一次答错不等于概念不会
模型明确差/比、起点、步数；区分单项与累计抄出公式不等于知道公式适用于哪里
解释能说明 n−1、端点 +1、为什么可以配对或错位相减表达简短可能是书写习惯，必要时口头补问
选择与效率方法对本题规模是否合适，是否能在规模改变时迁移列三四项很合理；机械套公式也可能更慢

逐层标记：独立且清楚 / 提示后做到 / 尚无证据。数值错误另加“运算待核”；未作答、没记录用时、照片不清时标“信息不足”，不计作概念错误。负公比等拓展单列，不据此否定核心掌握。

02 · 怎样实施，才不破坏诊断？

  1. D 组：8 题先做，先不展示讲义和答案。建议留 15–20 分钟作答空间，可适当延长；不是限时淘汰。只记录大致用时。
  2. 复习讲义：每次 2–3 节。让孩子解释示例，理解后再看折叠自检。自检是教学反馈，不计为独立诊断证据。
  3. P 组：16 题分两次。答题前不要说“这一题考等比和”。查资料或提醒可发生，但必须记录。看过答案后做对，与独立做对分开。
  4. T 组：8 题换情境与问法。允许画图和试算。重点看能否把题意翻译成可操作关系。
  5. S 组：核心内容已较稳定后，再做 8 题 / 建议 12 分钟。计时结束保留当时完成量。若太赶，先不提速，回到讲解；不把每题 90 秒视为统一合格线。
  6. R 组：48–72 小时后独立做 10 题。复测前不重看原题答案；是否做过同类题、是否得到提醒，都一起记录。若需要边学边测，也可以，但注明条件。

建议口头追问统一且中性：“你第一步在找什么？”“这一步为什么成立？”“如果题目换个数，你的方法还能用吗？”第一轮不在卡点当下透露题目对应公式，待初答封存后再进行教学追问。

03 · 从错法形成假设，再用另一题验证

看到的表现可能的解释下一步验证
把 n 当成间隔数起点没有纳入模型；也可能是代入时笔误请画 4 个位置并连线，再检查一个第 0 天情境
求和题回答最后一项单项 / 累计混淆；也可能漏读 sum让孩子分别说出 a₄、S₄ 含义，再做不同情境的累计题
两非相邻项直接相减作 d忽略项与项之间有多步问两项相隔多少个间隔，再用不同间距复测
等比和也用首末平均公式适用条件不清；或把数列类型看错分别检查连续差与比；用短反例验证“首末平均”
q=1 时出现 0/0忽略除法条件，或只记形式未理解和的意义把常数数列直接写成重复加法，重新解释 Sₙ
长列举正确但耗时可能理解但尚未形成快捷方法；也可能依赖局部规律请说明为什么每步成立，再把项数放大；不直接扣“方法分”
公式正确却结果错更可能是分数、幂或算术失误保留模型得分，单独复算关键一步；不要重新刷整章
熟悉题快，换情境就停可能靠模板识别，读题或建模尚弱比较同技能不同表述的关联题；用时间线/首末项重新建模

判定规则：一条错答只产生一条假设。优先寻找至少两道不同表述的独立作答，以及一次中性解释追问。证据冲突时保留两种解释；没有过程时先补证据，再出针对题。

04 · 后续补练怎样“换”，才有意义？

交回作答后，先选最影响迁移的 1–2 个断点，不重新布置整套。每个断点采用“微讲解 → 近迁移 → 换表述 → 边界反例 → 隔日检验”，每次约 6–8 题即可按实际表现调整。

05 · 下次交回后如何分析？

请给：题号 + 第一遍草稿（完整）+ 用时估计 + 帮助情况 + 订正。网页可导出 JSON / 文本，纸笔可拍清晰照片。草稿不清或关键步骤缺失时会先核实。

下一轮反馈应包含：① 结果与过程逐题核对；② 按知识维度归纳“已稳定 / 待验证 / 需补强”；③ 用相关题交叉证据解释判断；④ 区分概念、建模、运算、选择和速度；⑤ 给出少量有目的的变式与隔日复测；⑥ 用新作答验证干预是否有效。

证据记录示例：“Q甲与Q乙都把 5 个间隔写成 6；口头画位置图后能修正，所以暂怀疑序号建模不稳。安排一个零起点、一个中间项起算的变式。”这比“粗心”或“公式不会”更可操作。

覆盖边界：D、P、T、S、R 是教学诊断组，不是严格等值的标准化前后测。跨类型配对只比较共同能力，例如单项与总和的区分；不直接比较原始总分。讲义里的插项、百分比变化、排除端点及从相邻部分和反求单项等细分技能，没有全部安排独立的正式练习题；不能从本套总体表现推断它们均已掌握。若老师作业涉及这些类型，后续另加变式。

解题过程

参考答案

R09 基础

只考察下列每行给出的4个数。逐行判断：相邻差是否都相同？相邻的后一个数除以前一个数所得的比是否都相同？请写出证据。 甲：7，11，15，19 乙：24，12，6，3 丙：8，8，8，8 丁：1，2，4，7
