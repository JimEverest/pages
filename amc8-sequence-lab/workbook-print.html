怎么做

  1. D01–D08：先做，不翻讲义。会多少写多少。
  2. 阅读讲义后，分两次做 P01–P16；再做 T01–T08。

每题留下什么

答案 + 全过程（公式、画图、试算都可以）+ 大致用时 + 把握程度 + 帮助情况。用时不知道可留空。

本练习不使用计算器；若用了工具，请如实记录。不会做时写出卡点。保留第一次作答，订正另写。空白不够可加纸，并写清题号。

帮助代码：I 独立 / G 查讲义 / H 口头提醒 / A 看答案 / C 用工具。
把握程度：有把握 / 犹豫 / 试出或猜测 / 卡住。

这是专项训练，不是官方真题或整卷模拟。后续分析既看结果，也看解释、方法与迁移，不因没用公式判错。
本册不含答案；请在完成初答后由家长使用诊断手册。版本 2026-11-08。
